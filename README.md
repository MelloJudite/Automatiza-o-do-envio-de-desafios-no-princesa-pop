# Descrição:
Bot de automatização do envio de desafios sem aposta no princesa pop usando selenium.
Criado com o propósito de acelerar a subida de nível no jogo, esse bot não tem a intenção de estragar a experiência do jogador.

## MUITO IMPORTANTE:
É contra as diretrizes do princesa pop utilizar bots e derivados, podendo ocorrer o banimento da sua conta.
Portanto, não abuse desse bot, utilize com sabedoria esperando no mínimo três dias para rodar novamente.


## Como usar:
- É necessário instalar o navegador firefox caso não tenha.

- Adicione seu login e senha:
Renomeie o arquivo ".env.example" para ".env"
Adicione seu email e sua senha do princesa pop nos campos respectivos

- Instale as dependências rodando no terminal:
pip install python-dotenv
pip install selenium

- Rode o arquivo pelo terminal usando o comando abaixo e espere até que o seu navegador seja fechado automaticamente:
python app.py
